# Atención N1 de ABIERTA UGR

## Estado de la documentación

La base de conocimiento indica que existe un documento específico de **Atención N1** para responder a incidencias de ABIERTA UGR.

El contenido de ese protocolo no está incluido en la fuente consultada.

## Contenido pendiente

Cuando se disponga del documento de Atención N1, esta ficha deberá incorporar:

- alcance del primer nivel de atención;
- tipos de incidencias que puede resolver;
- comprobaciones iniciales;
- respuestas predefinidas;
- criterios de cierre;
- criterios de escalado a Atención N2;
- y unidades responsables.

## Criterio de uso provisional

Hasta que se incorpore el protocolo específico, esta ficha no debe utilizarse para deducir procedimientos ni responsabilidades.
