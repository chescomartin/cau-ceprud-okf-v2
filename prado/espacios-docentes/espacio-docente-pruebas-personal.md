# Espacio Docente de Pruebas Personal —EDPP—

## Definición

El **Espacio Docente de Pruebas Personal —EDPP—** es un espacio individual destinado a que el profesorado pueda practicar y probar el funcionamiento de PRADO.

No debe utilizarse como sustituto de un espacio docente oficial para impartir docencia ordinaria.

## Quién aparece en el espacio

El EDPP incorpora únicamente al docente titular con un rol que le permite gestionar el espacio.

Desde este espacio, el docente puede:

- probar la configuración de un curso;
- practicar con actividades y recursos;
- incorporar usuarios de prueba con rol de estudiante;
- incorporar usuarios con rol docente;
- familiarizarse con la gestión de la plataforma.

## Creación automática

El espacio se crea automáticamente cuando el docente dispone de docencia oficial en:

- PRADO Grado;
- o PRADO Posgrado.

La creación depende de la existencia de asignación docente oficial.

## Creación manual

Puede crearse manualmente cuando se trata de una persona que:

- todavía no tiene docencia asignada;
- puede acceder mediante el proveedor de identidad institucional;
- necesita realizar una actividad formativa o practicar con la plataforma;
- y la creación está justificada por el procedimiento interno.

La creación manual corresponde al personal técnico.

## Uso correcto

El EDPP debe utilizarse para:

- formación;
- pruebas;
- experimentación;
- preparación de actividades;
- conocimiento del funcionamiento de PRADO.

## Uso incorrecto

No debe utilizarse para impartir docencia oficial.

Cuando un docente necesita un espacio separado para una asignatura real, debe solicitar a su departamento un:

- [Espacio Docente Individual —EDI—](/prado/espacios-docentes/espacio-docente-individual.md)

## Código del espacio

El código del EDPP se forma mediante:

- el año académico;
- y el correo institucional del docente.

## Comprobaciones antes de crearlo manualmente

Comprobar:

1. la identidad de la persona;
2. el correo institucional;
3. que puede autenticarse mediante el IdP;
4. que todavía no dispone de un EDPP automático;
5. el motivo de la solicitud;
6. la actividad formativa o necesidad de prueba;
7. la plataforma en la que debe crearse;
8. el curso académico correspondiente.

## Casos frecuentes

### El docente tiene docencia oficial, pero no ve su EDPP

Comprobar:

- la plataforma;
- el curso académico;
- la asignación docente;
- el plazo de sincronización;
- la existencia del espacio.

### La persona todavía no tiene docencia

Puede valorarse la creación manual cuando necesita el espacio para formación o pruebas y puede acceder con su cuenta institucional.

### El docente utiliza el EDPP para docencia real

Debe informarse de que no es el uso previsto.

Cuando necesite un espacio separado para una asignatura oficial, deberá tramitar un EDI mediante su departamento.

### Solicita incorporar personas para hacer pruebas

El docente puede incorporar usuarios de la plataforma con roles de estudiante o docente, siempre dentro del uso de prueba del espacio.

## Información que debe registrarse

Cuando se cree manualmente, anotar:

- nombre y correo del docente;
- plataforma;
- curso académico;
- motivo de la creación;
- actividad formativa relacionada;
- fecha;
- técnico que realiza la actuación;
- resultado de la comprobación final.
