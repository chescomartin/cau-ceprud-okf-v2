# LMS: LaTeX y marcas

## Definición

El Tema de ayuda **LMS: LaTeX y marcas** se utiliza para clasificar incidencias relacionadas con la funcionalidad LaTeX y el uso de marcas en las plataformas educativas.

## Plataformas

La documentación interna lo relaciona con:

- PRADO Grado;
- PRADO Posgrado;
- E-CAMPUS;
- ABIERTA UGR.

## Criterio de clasificación

Debe utilizarse cuando el problema principal afecta a:

- la escritura o visualización de expresiones mediante LaTeX;
- el procesamiento de marcas;
- o el funcionamiento de esta funcionalidad dentro del LMS.

La documentación interna señala que se trata de una categoría poco utilizada.

Antes de asignarla, comprobar que la incidencia no corresponde principalmente a:

- cuestionarios;
- calificaciones;
- uso general del LMS;
- o edición de contenidos.

## Información mínima del ticket

Registrar:

- plataforma;
- curso;
- recurso o actividad afectada;
- expresión o marca utilizada;
- comportamiento observado;
- resultado esperado;
- mensaje de error;
- y, cuando sea posible, un ejemplo reproducible.

## Información aún no documentada

La documentación interna no detalla todavía:

- sintaxis admitida;
- filtros activados;
- configuraciones específicas por plataforma;
- errores conocidos;
- ni procedimientos de comprobación.

Esta ficha deberá ampliarse cuando exista información operativa suficiente.
