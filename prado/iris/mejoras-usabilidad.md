# Mejoras de usabilidad

## Definición

El Tema de ayuda **Mejoras de usabilidad** se utiliza para clasificar propuestas o incidencias relacionadas con la facilidad de uso de las plataformas educativas.

## Plataformas

La documentación interna lo relaciona con:

- PRADO Grado;
- PRADO Posgrado;
- E-CAMPUS;
- ABIERTA UGR.

## Ejemplo documentado

La base de conocimiento menciona como ejemplo:

- el desplegable de cursos `Futuros` o `En progreso` del Área personal de PRADO.

## Criterio de clasificación

Debe utilizarse cuando el problema principal se refiere a:

- dificultad para localizar una función;
- organización o presentación poco clara;
- comportamiento confuso de la interfaz;
- propuesta de mejora de navegación;
- o experiencia de uso de la plataforma.

Antes de asignarlo, comprobar que la incidencia no corresponde principalmente a:

- visibilidad de un curso;
- matrícula;
- acceso;
- error técnico;
- o una categoría LMS más específica.

## Información mínima del ticket

Registrar:

- plataforma;
- pantalla o función afectada;
- persona usuaria;
- comportamiento observado;
- resultado esperado;
- pasos realizados;
- y, cuando sea posible, una captura o ejemplo reproducible.

## Información aún no documentada

La documentación interna no detalla todavía:

- criterios para aceptar una propuesta;
- responsables de su evaluación;
- procedimientos de escalado;
- prioridades;
- ni estados de seguimiento.

Esta ficha deberá ampliarse cuando exista información operativa suficiente.
