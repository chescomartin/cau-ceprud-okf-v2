# TPV: Error

## Definición

El Tema de ayuda **TPV: Error** se utiliza cuando el problema principal del ticket es un error producido durante un pago mediante TPV.

## Ejemplo documentado

La documentación interna establece esta correspondencia:

```text
Pago error TPV → TPV: Error
```

## Criterio de clasificación

Debe utilizarse cuando:

- la persona intenta realizar un pago;
- el proceso se interrumpe o devuelve un error;
- y el problema principal está relacionado con el TPV.

Antes de asignarlo, comprobar que el ticket no corresponde principalmente a:

- información general sobre un pago;
- solicitud de certificado o justificante;
- exención o precio especial;
- matrícula;
- o un problema de acceso a la plataforma.

## Información mínima del ticket

Registrar:

- plataforma o servicio;
- curso, actividad o concepto de pago;
- persona afectada;
- fecha y hora aproximadas;
- importe;
- operación que intentaba realizar;
- mensaje de error;
- estado aparente del pago;
- y, cuando sea posible, una captura o justificante.

## Precauciones

No debe afirmarse que el pago se ha completado o rechazado sin comprobar la información disponible.

Cuando exista duda sobre el estado de la operación, debe dejarse constancia de:

- lo que muestra la plataforma;
- lo que indica la persona;
- y la comprobación pendiente.

## Información aún no documentada

La documentación interna no detalla todavía:

- plataformas asociadas;
- procedimientos de comprobación;
- códigos de error;
- unidad responsable;
- plazos;
- ni respuestas predefinidas.
