# LMS: Mensajería y foros

## Definición

El Tema de ayuda **LMS: Mensajería y foros** se utiliza para clasificar incidencias relacionadas con las herramientas de comunicación del LMS.

## Plataformas

La documentación interna lo relaciona con:

- PRADO Grado;
- PRADO Posgrado;
- E-CAMPUS;
- ABIERTA UGR.

## Criterio de clasificación

Debe utilizarse cuando el problema principal afecta a:

- la mensajería interna;
- los foros;
- el envío o recepción de comunicaciones;
- la participación en conversaciones;
- o la configuración de estas herramientas.

Antes de asignarlo, comprobar que la incidencia no corresponde principalmente a:

- acceso;
- matrícula;
- visibilidad;
- calificaciones;
- o uso general del LMS.

## Información mínima del ticket

Registrar:

- plataforma;
- curso;
- herramienta afectada;
- persona usuaria;
- comportamiento observado;
- resultado esperado;
- mensaje de error;
- fecha y hora aproximadas;
- y, cuando sea posible, una captura o ejemplo reproducible.

## Información aún no documentada

La documentación interna no detalla todavía:

- tipos concretos de incidencias;
- permisos necesarios;
- reglas de suscripción;
- problemas de notificaciones;
- diferencias entre plataformas;
- ni procedimientos de comprobación.

Esta ficha deberá ampliarse cuando exista información operativa suficiente.
