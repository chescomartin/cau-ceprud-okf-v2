# DPM: Error

## Definición provisional

El Tema de ayuda **DPM: Error** aparece en la documentación interna como una categoría de IRIS.

La fuente no aporta todavía:

- una definición;
- plataformas asociadas;
- ejemplos;
- criterios de clasificación;
- ni procedimientos de comprobación.

## Criterio de uso

Hasta que exista una definición institucional, debe utilizarse únicamente cuando:

- el asunto principal esté relacionado con DPM;
- y se trate de un error, no de una petición funcional.

Antes de seleccionarlo, debe comprobarse que el ticket no corresponde mejor a:

- [DPM: Peticiones](dpm-peticiones.md), cuando se trate de una solicitud;
- [INFO: General](info-general.md), cuando sea una consulta informativa;
- o una categoría específica de la plataforma afectada.

## Información mínima del ticket

Registrar:

- plataforma o servicio;
- persona afectada;
- acción que intentaba realizar;
- comportamiento observado;
- resultado esperado;
- mensaje de error;
- fecha y hora aproximadas;
- y, cuando sea posible, una captura o ejemplo reproducible.

## Información pendiente

Debe documentarse:

- significado y alcance de DPM;
- plataformas relacionadas;
- tipos de errores;
- procedimientos de comprobación;
- unidad responsable;
- criterios de escalado;
- y respuestas predefinidas.
